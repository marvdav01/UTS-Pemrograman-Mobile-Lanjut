# RecipeKu – Indonesian Recipe Explorer

Aplikasi mobile resep masakan menggunakan **React Native (Expo)**, **Axios**, **TanStack Query v5**, dan **React Navigation v7** dengan sumber data **REST API DummyJSON Recipes** (`https://dummyjson.com/docs/recipes`).

## Cara Menjalankan
```bash
npm install --legacy-peer-deps
npx expo start
```
Untuk menjalankan pada antarmuka Web:
```bash
npx expo start --web
```
